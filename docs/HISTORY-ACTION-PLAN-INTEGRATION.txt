CARA PASANG (JALANKAN DARI ROOT PROJECT, FOLDER YANG BERISI artisan):
1. Backup project dan database terlebih dahulu.
2. Ekstrak patch:
   unzip -o /path/ke/action_plan_patch_v2.zip -d .
3. Bersihkan cache Laravel:
   php artisan optimize:clear
4. Simulasikan migration:
   php artisan migrate --pretend
5. Jika SQL simulasi benar dan koneksi DB mengarah ke database yang tepat:
   php artisan migrate
6. Verifikasi route:
   php artisan route:list --path=decision -v
7. Kompilasi view:
   php artisan view:cache
   php artisan view:clear
8. Jalankan test:
   php artisan test --testsuite=Feature

JANGAN menjalankan migrate:fresh, db:wipe, atau mengimpor ulang dump database
ke database yang berisi data produksi.
